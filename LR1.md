# Тема: Лабораторная работа #1 — Указатели

## Упражнения с malloc и сложными однострочными выражениями в С с присваиваниями внутри

### Постановка задачи

Внутри функции `int main(void) { /*...*/ }` определить указатель:

`double ***pointer = NULL;`

Инициализировать этот указатель адресом другого указателя типа `double **`, который указывает, в свою очередь, на переменную `double`. Используйте `pointer` для записи и чтения в эту переменную значения 2.

При этом выполнить: - Использовать функции типа `*alloc(...)` для выделения оперативной памяти под динамические объекты; - Записать и вывести число 2 на экран, используя указатель `double ***pointer = NULL;`; - Использовать функцию `free(...)` для освобождения оперативной памяти, выделенной под динамические объекты. - **Не использовать никаких идентификаторов переменных, кроме `pointer`.**

### Математическая модель
Модель памяти: цепочка из трёх динамических объектов, связанных указателями.

```
pointer ──► [ double ** ] ──► [ double * ] ──► [ double = 2 ]
 (стек)         (куча)           (куча)            (куча)
```

| Выражение  | Тип          | Что представляет                                  |
|------------|--------------|---------------------------------------------------|
| `pointer`  | `double ***` | адрес динамического объекта типа `double **`      |
| `*pointer` | `double **`  | адрес динамического объекта типа `double *`       |
| `**pointer`| `double *`   | адрес динамического объекта типа `double`         |
| `***pointer`| `double`    | само значение (число 2)                           |

Порядок работы:

1. Выделить память под `double **` и записать её адрес в `pointer`.
2. Выделить память под `double *` и записать её адрес в `*pointer`.
3. Выделить память под `double` и записать её адрес в `**pointer`.
4. Записать `2` в `***pointer`, вывести значение на экран.
5. Освободить память в обратном порядке: `**pointer`, `*pointer`, `pointer`.

### Список идентификаторов

| Имя переменной | Тип данных   | Описание                                                                 |
|----------------|--------------|--------------------------------------------------------------------------|
| `pointer`      | `double ***` |указатель на цепочку динамических объектов, через него записывается и читается число 2 |

### Код программы

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    double ***pointer = NULL;

    printf("%f\n", *(*(*(pointer = malloc(sizeof(double **))) = malloc(sizeof(double *))) = malloc(sizeof(double))) = 2);

    printf("%f\n", ***pointer);

    free(**pointer);
    free(*pointer);
    free(pointer);

    return 0;
}
```
